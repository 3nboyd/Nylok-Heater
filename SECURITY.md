# Security and safety reporting

This repository describes prototype power electronics. Treat unsafe electrical, thermal, battery, or control behavior as a security-relevant issue.

Do not publish exploit details or instructions that could predictably cause injury or equipment damage. Instead, use GitHub's private vulnerability reporting for this repository if enabled, or contact the repository owner through their GitHub profile.

Include the affected revision, failure mode, test conditions, reproduction information, and suggested mitigation. Do not energize suspect hardware merely to reproduce a report.

There are no supported production versions. The current design is a non-fabrication-ready concept.
